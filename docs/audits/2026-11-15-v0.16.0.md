## Capture procedure and limits

Export only the immutable tag outside checkouts:

```sh
mkdir -p /tmp/tycho-site-v0160/source /tmp/tycho-site-v0160/evidence
git -C /Users/didik/Code/personal/tycho archive v0.16.0 | tar -x -C /tmp/tycho-site-v0160/source
cd /tmp/tycho-site-v0160/source
patch -p1 < /Users/didik/Code/personal/tycho-site/docs/audits/v0.16.0/capture.patch
sh /Users/didik/Code/personal/tycho-site/docs/audits/v0.16.0/run-capture.sh
```

The patch changes only the capture runner in the exported archive: output paths/names, synthetic saved user/inquiry/Summary events, mobile capture, and a bottom-gap assertion that retains row-clipping and overflow checks. It does not modify product UI source. The runner uses `env -i`, isolated HOME/TYCHO_HOME/config/logs/credentials, and two inert sleep processes for running rows. No real harness or provider runs. All project and session content is synthetic. The archive's existing capture fixture uses Atlas Web, Compass API, and Beacon Mobile. Host is the synthetic local server label; no real host or token is captured.

Ruby 4.0.9, Node 22.23.4, Google Chrome 157.0.8103.52. Desktop: 1440 × 900 at scale 1. Phone: 390 × 844 at scale 2 (780 × 1688 output). The runner installs Playwright in its temporary directory. The site browser checks use the lockfile's Playwright package. The social image is a 1200 × 630 Chrome render of [the saved composition](https://github.com/firewalker06/tycho-site/blob/release/v0.16.0-site/docs/audits/v0.16.0/og.html). The original product source and live Tycho server are unchanged.
