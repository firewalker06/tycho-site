### Exact-release first-run findings

These source files at `ec3cbd49a3f5ba58f9ec6b83b505328955c3ae3c` define the flow: `config/hq.yml.example`, `lib/hq/domain/onboarding.rb`, `lib/hq/domain/constants.rb`, `lib/hq/serve_command.rb`, `lib/hq/remote_server.rb`, `lib/hq/remote_ui/assets/app.js`, `lib/hq/domain/harness_auth_check.rb`, and `bin/setup`.

- The default registry is empty. `serve` loads the bundled empty config; it does not auto-create a project. The onboarding button **Create Welcome Sandbox** creates the built-in project with key `welcome`, name **Welcome Sandbox**, and files `README.md` and `notes.md` at `~/tycho-projects/welcome`. This is starter bootstrap, not manual registration of a user repository. The earlier detailed guide's `~/.tycho/workspaces/welcome` path was corrected.
- The Welcome project page opens **New agent**. Harness selection is inside **Options → Advanced**. The full form action is **Create and Run**. The homepage and detailed guide use these actual labels.
- `tycho serve --host 127.0.0.1 --port 7373` binds to localhost and bypasses Tailscale auto-binding. A fresh localhost setup works without a remote token. A server with a synthetic token rejected tokenless setup with HTTP 401 and accepted its synthetic bearer with HTTP 200. The test used an ephemeral port to avoid the live server.
- The synthetic Codex auth probe reported unauthenticated before a fixture marker and authenticated afterward. Executable availability alone does not prove provider authentication. The page requires an installed, authenticated harness before its first run.
- `bin/setup --check --remote` failed under macOS default Bash 3.2 with `PROFILES[@]: unbound variable`. It passed under Bash 5.3.20 with Ruby 4.0.9, Bundler 4.0.20, Go 1.27.4, and native build tools, with expected missing-optional-tool/config warnings. The source requirements now specify Bash 5 or newer on PATH. No product fix is included.
- Microsoft documents Windows-browser access to WSL Linux services through localhost: [WSL networking](https://learn.microsoft.com/en-us/windows/wsl/networking#accessing-linux-networking-apps-from-windows-localhost). Homebrew documents Linux and WSL2 support: [Homebrew on Linux](https://docs.brew.sh/Homebrew-on-Linux). This run did not install Tycho on physical Linux, WSL2, or Intel macOS and does not claim those platform tests.
