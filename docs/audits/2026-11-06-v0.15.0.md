# Tycho v0.15.0 site audit

This audit records site work started before the product release merge, under the operator's explicit exception to the normal start-after-merge rule, then updated after publication. It follows [site release instructions](https://github.com/firewalker06/tycho-site/blob/main/docs/RELEASING.md) and [ADR 004](https://github.com/firewalker06/tycho-site/blob/main/docs/decisions/adr-004-release-version-and-screenshots.md).

- Released source: [Tycho v0.15.0](https://github.com/firewalker06/tycho/releases/tag/v0.15.0), commit [e34e2cd766762e9c5b8f76e4276523596ef8afb9](https://github.com/firewalker06/tycho/commit/e34e2cd766762e9c5b8f76e4276523596ef8afb9). Its tree matches the former source from [release-prep PR 338](https://github.com/firewalker06/tycho/pull/338).
- Source files: `docs/releases/v0.15.0.md`, `CHANGELOG.md`, `docs/UPGRADING.md`, `lib/hq/cli_command.rb`, `lib/hq/domain/executable_resolver.rb`, and the release's Remote UI code.
- The product tag and GitHub release now exist. The release URL and source links were checked after publication. Homebrew publication is a separate gate and remains under review.
- Product release-prep validation is recorded on PR 338. This site audit does not use the running daemon or the real Tycho home. The Tycho CLI is not on this shell's PATH, so a live agent and schedule listing could not be completed without reading the protected real home.

## Product and documentation review

- Installation and upgrade copy uses Ruby 4.0.9 or newer, no new gem dependency, and no manual data migration. It names the Pi 0.84.4 RPC update, native stdin prompts, custom transport modes, and experimental agy support with unverified authentication and sandbox isolation.
- Platform copy says Apple Silicon macOS and Linux remain the bottle targets and Intel macOS remains source-only since v0.11.0. The Homebrew release link is present but its release page is not live yet, so no bottle availability is claimed.
- The CLI reference identifies the exact source commit. Comparing `lib/hq/cli_command.rb` between v0.14.1 and this source found no new or removed command forms. The documented `agent create --harness` choices now include experimental agy. The executable resolver confirms the built-in `agy` key; custom profiles with that key must be renamed.
- The site keeps v0.14.0 and v0.14.1 as historical references. `check:links` permits these two historical release tags and requires every other Tycho release link to match the homepage badge.
- Concept, harness, Remote UI, and upgrade guidance now describe the appearance choice, send and inquiry recovery, custom prompt transports, updated Pi contract, serve diagnostics, and agy limits. Unchanged CLI, project, schedule, configuration, and lifecycle details were checked against the release source. The only CLI registration change is the `agy` harness choice.

## Screenshot inventory and decisions

Captures were made from the former release-prep commit `69d76f3c632042860acefa049a6172e98a0352a7`, before the tag existed. After publication, its tree was checked against the released commit above and found identical. The source was exported with `git archive` to a temporary directory outside both checkouts. The product checkout and source files were not changed. The product capture script was changed only in that temporary archive: output names and output directory were redirected; its grouped-list assertion was corrected for the default flat list; and a 390 × 844 phone capture was added. The product source still contains that capture assertion defect.

To repeat the source export from the published tag, run this from the Tycho product checkout:

```bash
mkdir -p /tmp/tycho-v0150-source /tmp/tycho-v0150-output /tmp/tycho-v0150-home /tmp/tycho-v0150-node
git archive v0.15.0 | tar -x -C /tmp/tycho-v0150-source
npm install --prefix /tmp/tycho-v0150-node --no-audit --fund=false --ignore-scripts playwright@1.65.0
```

The capture script was `bin/capture-site-quickstart`. In the temporary archive, `OUTPUT_DIR` was changed to `ENV.fetch("TYCHO_CAPTURE_OUTPUT_DIR", "/tmp/tycho-v0150-output")`; both output names were changed to v0.15.0; and Playwright's node directory was set to `/tmp/tycho-v0150-node`. The old grouped-list assertions were changed to expect one `.agent-flat-list`, and the old bottom-gap range check was removed while clipping checks remained. The added phone page used a 390 × 844 viewport and device scale 2. The clean-environment runner used:
