### Harness catalog evidence

`tycho harness list` is local-only and has no `--server` forwarding. Offline listing reads built-in fallback and configured `harness_catalogs`, including custom harnesses, without executing tools, checking authentication, or contacting providers. `--harness` and `--model` are exact and case-sensitive. Missing catalog data is not proof of provider availability or lack of support.

`--discover` runs the local catalog commands used by Settings; those commands can need installed tools, credentials, or provider/network access. `catalog_source` names the source or fallback. Tycho adds no separate provider API query or authentication check for this command. Discovery does not validate entitlement or a model/reasoning pair. Project/template overrides are not listed.

Unknown defaults remain JSON `null` or text `unknown; harness decides`. The Claude `low`, `medium`, `high`, `xhigh`, and `max` values for `claude-opus-5-5` are harness suggestions; model support/defaults remain unknown. A model-specific reasoning list requires model-specific source evidence and is identified through `reasoning_scope`.

Isolated CLI probes verified offline no-tool execution, exact-filter rejection, custom catalog merging, unknown defaults, no remote option, and model versus harness reasoning. Optional discovery used only a synthetic local Codex command; no real provider or credential was used. All 43 subcommand help requests passed.

### Archive and notification limits

Remote UI Start New saves a fresh replacement before archiving its source. Start with Handoff archives after the replacement starts. Recurring schedule ownership follows the replacement. Context replacement blocks running work, unresolved inquiries, and ordinary or mixed queues. Ordinary CLI `agent clone --handoff` retains its source.

Manual archive in Remote UI stops active work and cancels inquiries. It does not execute queued work. Undelivered user prompts are declined with a reason; protected callbacks are superseded with a reason and retained read-only. Delivered or in-flight work is marked aborted with uncertainty. CLI `agent archive` requires a running session to be stopped first.

Settings notification traces/export and the explicit current-browser test sender improve diagnosis. Provider acceptance and synthetic Chrome checks do not establish native Edge activation, installed-PWA focus, or cold-window behavior. This audit sent no real test push and makes none of those claims.
